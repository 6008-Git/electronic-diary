# 一日手账 (electronic-diary)

一个手机端优先的**电子日记 PWA**，记录每天的体重、消费、单词、基础打卡与感想。数据默认存在本地，可选开启云同步。用 Edge/Chrome 打开后可「安装到主屏幕」，像原生 App 一样使用。

## 功能

| 模块 | 说明 |
| --- | --- |
| 壹 今日体重 | 纯数字，单位 kg |
| 贰 今日消费 | 默认「午饭 / 晚饭」两行（不可删除），可自由添加行；标题右侧实时显示当日总额 |
| 叁 今日单词 | 纯数字，记录当天背诵的单词数量 |
| 肆 今日基础 | 单选项：刷牙 / 洗脸 / 护肤 / 戒欲，默认红色，勾选后变绿 |
| 伍 今日锻炼 | 暂留空，供后续扩展 |
| 陆 今日感想 | 富文本编辑器，支持粗体 / 斜体 / 下划线 + 红黄绿蓝黑五色 |

### 感想骨架（三条默认行）

1. **今日饮食：**（蓝）— 实时同步「今日消费」中填写的备注，以「；」间隔，可在后面自行追加内容
2. **昨日感悟：**（绿）— 内容恒为前一天的「今日感悟」，刷新也不变
3. **今日感悟：**（红）— 默认留空，手动填写

第三条之后可自由编写。

### 往昔 / 我的

- **往昔**：按「2号，周五」格式列出所有记录，点击弹窗查看详情（支持修改日期、跳转编辑）
- **我的**：记录天数 / 累计花费 / 累计单词统计；体重折线图、消费折线图、单词柱状图，均支持 **日 / 月** 切换

### 其他

- **逻辑日期**：凌晨 4 点前填写的内容，算作前一天
- **数据存储**：`localStorage` 本地存储，可选云同步（Flask 后端）
- **导入导出**：JSON 格式，**所有 key 均为中文**
- **PWA**：`manifest.json` + `sw.js`，支持安装到主屏幕、离线访问

## 目录结构

```
电子日记/
├── public/
│   ├── index.html          # 主程序（UI + 逻辑）
│   ├── manifest.json       # PWA 清单
│   ├── sw.js               # Service Worker
│   └── icons/              # 应用图标
│       ├── icon-192.png
```

## 本地运行

```bash
pip install flask
python3 server.py
# 打开 http://localhost:8000
```

## 云同步

在「我的 → 云同步」输入一个口令（如手机号）即可开启。后端用 sha256 哈希口令作为文件名，口令本身不落盘明文。

- `GET  /api/sync/<code>` — 拉取云端数据
- `POST /api/sync/<code>` — 推送本地数据
- 合并策略：按每天的「更新时间」字段，新者覆盖旧者

## 技术栈

纯前端 **HTML + CSS + 原生 JavaScript**（无框架、无构建），后端为轻量 **Flask**。
